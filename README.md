# Base-de-datos-
Una pequeña base de datos de mi almario 
## Lo aprendido

En lo aprendido en el TICKET: **PRACTICAR SQL BÁSICO CON SQL SERVER** pude reforzar varios conocimientos que ya tenía y también pude aprender, mediante investigación, otros que no conocía y no sabía cómo utilizar.

En un principio hice un pequeño análisis sobre en qué se iba a basar mi base de datos y llegué a la conclusión de que se iba a basar en un ejemplo que ya habíamos tratado anteriormente. Después de eso, definí 4 tablas con las cuales iba a empezar a trabajar.

Luego empecé a utilizar los códigos que se me asignaron en el TICKET. Usé **CREATE DATABASE** y **USE** para crear y seleccionar la base de datos. Después utilicé **CREATE TABLE** para crear las tablas que iba a utilizar: **Calzado, T-shirt, Pantalones y Camisas**.

Para poder crear las tablas tuve que utilizar **INT, IDENTITY, PRIMARY KEY, DECIMAL(3,1), VARCHAR y NULL**, aprendiendo para qué servía cada uno.

Después de crear las tablas utilicé **SELECT * FROM** para consultar y poder ver la información que tenían las tablas. Para poder agregar información primero utilicé **INSERT**, junto con **INTO** y **VALUES**, para introducir los datos en las tablas.

También puse en práctica **UPDATE**, que sirve para modificar algunos datos, utilizando **SET** y **WHERE**. Luego utilicé **DELETE** para eliminar registros que ya no quería, utilizando nuevamente **WHERE** para seleccionar específicamente cuál registro quería eliminar.

También aprendí a utilizar **WHERE**, que me ayudó a seleccionar los datos que cumplían con una condición. Después utilicé **ORDER BY ASC/DESC** para poder visualizar los resultados de una consulta en el orden que yo quisiera.

Por último, aprendí sobre **JOIN**, que sirve para unir información de diferentes tablas utilizando una relación entre ellas. Con esto pude entender mejor cómo se pueden trabajar varias tablas dentro de una base de datos.
